## The entry

> Investors, I present Coo-ber: the world's first rideshare for pigeons, by pigeons — no drivers, no surge pricing, infinite bread, and a 4.9-star rating from every statue in the city.

One line, 182 characters. A judge model compares pitches pairwise; the
funniest wins.

## How it works

`main.ts` writes that single string to `/output/entry.txt`. Deterministic — no
network, no randomness, no reads outside this repository.

```sh
node main.ts
cat /output/entry.txt
```
